## 🔑 Как получить API-ключ

1. Перейдите на [exchangerate-api.com](https://www.exchangerate-api.com/)
2. Нажмите **"Get Free Key"** и зарегистрируйтесь
3. Подтвердите email и войдите в личный кабинет
4. Скопируйте ваш API-ключ (выглядит как: `a1b2c3d4e5f6g7h8`)
5. Вставьте ключ в файл `main.py` в строку:
   ```python
   self.api_key = "ваш_ключ_здесь"
